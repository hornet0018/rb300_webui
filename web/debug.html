Linear Calibration (Wheel Radius)

1. Place robot on flat floor. Click Start.
2. Robot moves forward 1m.
3. Measure actual distance and enter it below.
4. Click Calculate to get new radius.

--

Rotation Calibration (Wheel Separation)

1. Place robot and mark orientation. Click Start.
2. Robot rotates 360° in place.
3. Check if it returned to start orientation.
4. Enter actual rotation and click Calculate.

📡 LiDAR mode: place a flat wall/board ~0.5-2m in front of the robot. The robot will auto-capture the true rotation angle from LiDAR scan before/after rotation.
